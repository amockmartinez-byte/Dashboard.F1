# Dashboard.F1
README – Análisis y Dashboard de Fórmula 1 (Dataset F1 2023)
Descripción General


Este proyecto analiza datos oficiales de la temporada 2023 de la Fórmula 1 utilizando el dataset Ultimate F1 2023 disponible en Kaggle.

Se procesan datos de pilotos, equipos, circuitos, carreras, tiempos de vuelta y estrategias de boxes para generar visualizaciones clave. 

Objetivos
-Analizar el rendimiento de los pilotos a lo largo de la temporada

-Identificar los constructores más competitivos

-Evaluar estrategias mediante pit stops

-Estudiar tiempos de vuelta y consistencia

-Crear un dashboard informativo para visualización 

Estructura del Proyecto
El dataset está compuesto por varios archivos:
-Archivo
-Descripción
-drivers.csv
-Información de pilotos
-constructors.csv
-Equipos/constructores
-circuits.csv
-Datos de circuitos
-races.csv
-Información de cada carrera
-results.csv
-Resultados oficiales
-lap_times.csv

  Tiempos de vuelta por piloto
-pit_stops.csv
-Paradas en pits
-Tecnologías Utilizadas
-Python
-Pandas
-Matplotlib
-Google Colab

Análisis Realizados
-Pilotos con más puntos de la temporada
-constructores con mayor puntuación acumulada
-Promedio de posiciones finales por piloto
-Cantidad de pit stops por carrera
-Tiempos de vuelta promedio por piloto

Dashboard Final
El dashboard incluye 4 gráficos claves:
-Top pilotos por puntos
-Mejores constructores
-Posición final promedio
-Pit stops por carrera
Esto permite una visualización clara y sencilla del rendimiento en la temporada 2023.

Cómo usar este proyecto
Descargar el archivo ZIP del dataset desde Kaggle
Subirlo directamente a Google Colab
Ejecutar el código completo proporcionado
Visualizar los gráficos y el Dashboard  

Conclusiones
El análisis revela tendencias importantes en rendimiento, estrategias y consistencia entre equipos y pilotos.
Este proyecto sirve como base para ampliaciones más avanzadas, como dashboards interactivos o modelos predictivos.
